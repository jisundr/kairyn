# The backlog has no visual index

**Raw request:** "Add a backlog page to the kairyn repo: one HTML file that shows every idea in docs/backlog/, built from those files by a script" (Jayson De los Reyes, 2026-11-25, through an Orca coordinator, with a prototype page)

**Problem (confirmed by Jayson De los Reyes, 2026-11-25, grill):** To see the backlog, a person reads `README.md`, which lists triaged ideas only, then opens each idea file. There is no single view of every idea with its appetite, capture date and problem. Consumer repos get no such view either. The owner's words: "backlog html will be used just like readme.md but more visual, and it includes the other backlogs".

**Evidence:**
- `docs/backlog/` holds 19 idea files; `README.md` lists 5 of them.
- A repo-only prototype (`scripts/backlog_html.py`, WIP commit `c46a131`) built the page. The grill dropped it for a shipped feature.

**Decided (2026-11-25, grill):** Ship it in the plugin as `/kairyn:backlog`. A stdlib script writes one self-contained, offline, view-only page to `.kairyn/backlog.html` and git-ignores it. No status on the page. Details: the task's `CONCEPT.md`.
