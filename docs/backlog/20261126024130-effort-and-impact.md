# Effort and impact on backlog ideas, in place of appetite

**Raw request:** add effort and impact to backlog ideas (owner, 2026-11-26, through Orca).

**Problem (AI draft, needs a human to confirm):** An idea has only `appetite` (big or small batch). It does not say how much an idea is worth, so the backlog cannot put high-value, low-cost ideas first. Most ideas have no appetite.

**Evidence:**
- `appetite:` is set in 6 of 19 earlier idea files; the README table has one Appetite column.
- `backlog_html.py` reads `appetite`, filters by it and lists ideas newest first.

**Decided (2026-11-26, grill):** Effort and impact, each Low / Medium / High, replace appetite. The AI proposes both at capture; the owner confirms at triage. Both show in idea files, the README table and the backlog page, which filters by both and sorts by impact (high first), then effort (low first). The AI proposes both for each existing idea; the owner confirms them in one list. Details: the task's `CONCEPT.md`.
