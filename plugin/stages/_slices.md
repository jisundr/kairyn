# Slices and test plan

Rules for the Tasks and Test plan sections of `DESIGN.md`.

## Tasks
Cut the option into vertical slices `T<n>`, T1 the tracer bullet. Each slice crosses every layer, or says why not. Each has `after:` and `Done: `<command>``. Mark `(approval)` on a slice whose files match `afk.yml` `approval:`.

## Test plan
Number the acceptance criteria `AC<n>` in their `REQUIREMENTS.md` order. Give each one a Test plan row with its tasks and a test. If only a person can show it, such as in a real session, write `Manual: <what to run>` as its test.
